# Benchmark Fixtures Directory

This directory stores ephemeral benchmark fixtures generated by `scripts/load/seed-benchmark-data.js`.

## Security Rules
- Concrete fixture data files (`*.json`) contain runtime benchmark tokens and signing keys and are strictly `.gitignore`d.
- Never commit `benchmark-fixtures.json` to source control.
- To generate deterministic fixtures for testing, run:
  ```bash
  node scripts/load/seed-benchmark-data.js --count=25
  ```
- To cleanup benchmark data, run:
  ```bash
  node scripts/load/cleanup-benchmark-data.js
  ```
